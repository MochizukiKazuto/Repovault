Cara 1: Console Script Sekali Klik di Browser (Tanpa Instal Ekstensi)

  1. Buka threads.net/saved di browser desktop dan scroll ke bawah untuk memuat postingan simpananmu.
  2. Tekan F12 (atau klik kanan → Inspect), lalu buka tab Console.
  3. Salin script di bawah ini, tempel di Console, lalu tekan Enter (link otomatis tersalin ke clipboard!):
(() => {
  const urls = new Set();
  document.querySelectorAll('a[href]').forEach(a => {
    const href = decodeURIComponent(a.href || '');
    const m = href.match(/https?:\/\/github\.com\/([a-zA-Z0-9_.-]+\/[a-zA-Z0-9_.-]+)/);
    if (m) urls.add('https://github.com/' + m[1].replace(/\.git$/, ''));
  });
  const text = [...document.body.innerText.matchAll(/github\.com\/([a-zA-Z0-9_.-]+\/[a-zA-Z0-9_.-]+)/g)];
  text.forEach(m => urls.add('https://github.com/' + m[1].replace(/\.git$/, '')));
  const res = JSON.stringify([...urls], null, 2);
  copy(res);
  alert('Berhasil menyalin ' + urls.size + ' link GitHub ke clipboard! Sekarang tempel di RepoVault.');
})();

Cara 2: Chrome Extension Pendamping (Auto-Scroll & Export)

Jika kamu mengunduh paket ZIP RepoVault, di dalamnya sudah tersedia folder extension/ (Manifest V3). Cukup buka chrome://extensions → aktifkan Developer Mode → klik Load unpacked → pilih folder extension/. Ekstensi tersebut dapat melakukan auto-scroll halaman Saved Threads dan mengekspor seluruh link GitHub ke format JSON untuk ditempel di Tab 1.
